🔗 Connect your accounts

Both keys are stored only in this browser — never sent to anyone else, never saved in the repo.

GitHub Required

Lets the dashboard run checks for you and save your changes.

How do I get one?
1. Open this GitHub page and create a new token.
2. Under Repository access, choose Only select repositories and pick this one.
3. Under Permissions, turn on Contents: Read and write and Actions: Read and write.
4. Generate it, copy it, and paste it above. Scoping it to just this one repo means the worst case if it ever leaked is limited to this repo — not your whole GitHub account.

Claude Optional

Only needed for the chat feature in History.

How do I get one, and is this safe?
Get one at platform.claude.com under Settings → API Keys. This page uses it to talk to Claude directly from your browser — Anthropic's own supported way of doing that for a personal tool like this one. Treat it like a password: it's stored only in this browser, and anyone with access to this browser profile could use it.

🎛️ How thorough should checks be?

Higher settings find more but cost a little more. The defaults are a good balance for most people.
